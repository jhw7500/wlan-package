　IP 주소 리스트(128개)는 비휘발성 메모리상에 저장되며, 기판 기동 시에 비휘발성 메모리에서 값을 읽어들여 관리된다.
　본 커맨드 발행 시에는, 재기록용 임시 메모리 영역의 값을 교체하고, 최종 IP 주소 리스트 수신에 따라 비휘발성 메모리에 저장하여 IP 주소 리스트를 교체한다.
　IP 주소 리스트에는 리스트의 시작·종료를 나타내는 플래그(List　Boundary　Flag)가 설정되어 있으며, 시작(0x0001), 계속(0x0000), 완료(0x0002), 시작 및 완료(0x0003)가 설정되어 있다. 비휘발성 메모리에 대한 재기록 처리(비휘발성 메모리의 소거와 기록)는 리스트의 종료 수신 시에 실행한다.
　IP 주소 리스트 변경 처리에서 리스트의 종료 수신 전에 IP 주소 변경을 요구받은 경우에는,IP주소 변경의 경합으로 처리하여, IP 주소 변경은 NG로 처리된다.
즉, 커맨드에 갱신할 리스트번호가있으므로 전체 교체는 맞지않다

->[검증보강 2026-06-11] 원본 그림 3-2 도형 재확인: 재송 화살표는 **새 SN=12를 단 제어요구**("패킷 송신마다 번호 가산"), 무선 기판은 동일 커맨드로 판단해 **대기 중이던 SN=11(응답 의무)을 폐기**하고 처리 완료 후 SN=12로 응답. 즉 중복 판단 기준은 'SN 동일성'이 아니라 **처리 실행 중 동일 커맨드의 새 요구 도착**임. md 번역본의 "(SN=11)은 폐기" 괄호 경계 오류는 정정 완료. 구현 시 이 의미로 설계할 것.
